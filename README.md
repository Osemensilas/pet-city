# Pet City 🐾

Pet City is an e-commerce web app for pet products including food, pharmacy items, accessories, and consultant booking.

## 🚀 Features
- Shop by pet
- Shop by brand
- Product details page
- Cart system
- Pet clinc section
- store

## 🛠️ Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## 📁 Project Structure
- /app → Pages and routes
- /components → Reusable UI components
- /public → Images and static files

## ▶️ Getting Started

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```
